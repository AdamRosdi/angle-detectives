# Angle Detectives 🔍

A child-friendly, interactive web application created for Year 4 pupils to explore, recognise, and name angles.

## Learning Objective
> Pupils can recognise and name right, acute and obtuse angles on rectangles, squares and triangles (KSSR Year 4 Mathematics 6.1.1).

---

## Game Overview

`Angle Detectives` consists of three interactive learning missions:

1. **Angle Lab (`lab.html`)**:
   - An interactive laboratory where pupils can drag arms and vertex points to experiment with different angle types and triangle shapes.
   - Includes a drag-and-drop sorting game to categorize angle cards into Right, Acute, and Obtuse angle boxes.

2. **Detective Quiz (`quiz.html`)**:
   - A 10-question interactive quiz that tests pupils' angle recognition skills across basic angles, rectangles, squares, and various triangles (scalene, isosceles, equilateral).

3. **Angles Around Us (`real-life.html`)**:
   - An interactive classroom and playground scene where pupils discover hidden angles in everyday objects such as windows, books, pizza slices, scissors, playhouse roofs, and ladders.

---

## Colour Coding Conventions
Across the application, angles are visually reinforced with standard colour codes:
- 🟩 **Green**: Right Angles (Square corner, exactly 90°)
- 🟦 **Blue**: Acute Angles (Small & sharp, smaller than 90°)
- 🟧 **Orange**: Obtuse Angles (Big & wide, between 90° and 180°)

---

## How to Use

1. Open `index.html` in any standard modern web browser.
2. Read the **How to Play** guide or angle reference cards on the home page.
3. Choose any mission button (**Angle Lab**, **Detective Quiz**, or **Real-Life Angles**) to start investigating.
4. Track your visit progress using the **Your Detective Badges** card on the home page.

*Note: Session progress is kept in memory during your visit and resets when the page is refreshed.*
